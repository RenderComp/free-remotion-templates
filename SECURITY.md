# Security policy

This repository contains Remotion templates (React components) and no server-side code, credentials, or network services.

If you believe you have found a security issue in one of the templates, please use GitHub's private vulnerability reporting on this repository ("Security" tab → "Report a vulnerability") rather than opening a public issue. Reports are handled on a best-effort basis; there is no guaranteed response time.

Vulnerabilities in Remotion, React, or other dependencies should be reported to those projects directly.
